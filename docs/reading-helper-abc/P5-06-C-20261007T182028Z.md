## Item 1 — F1: no provider logs an error whole (`d313cc09`)

**Code.** A new `lib/llm/providers/error-kind.ts` exports `errorKind(err)`: the error's kind (`err instanceof Error ? err.name : typeof err`) and, when the error carries an integer HTTP status in `status` (first) or `code` (second), that number: `ApiError status 400`, `Error code 429`, `string`, `Error`. Its comment says why (an SDK builds the message from the response body, a body can quote the request, the request holds the reader's words, `AGENTS.md` keeps anything per-user out of a shared log). Seven lines use it and nothing else changed: the six in `gemini.ts` (the reader's-key provider: digest, JSON call, vision call; the server's Vertex provider: the same three) and the one in `lib/feed/tier2-rerank.ts`.
