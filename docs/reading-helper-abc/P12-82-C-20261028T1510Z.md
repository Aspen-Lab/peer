## 2. The rule as built

- **`titleFaceChange(previous, next, gap, pitch, body, context?)`** lets `next`, in another face than `previous`, go on with the caption when
  1. the caption has not changed face yet (no consecutive pair of its lines so far differs in face);
  2. either `previous` is the caption's first line (`captionOf(previous)`: the line that opens with the label), or `next` is set smaller than the body (`next.size <= body.size - 0.6`, `TITLE_SMALLER_BY`);
  3. the gap to `next` is the caption's own leading within `TITLE_PITCH_TOLERANCE` (20 %), where the leading is, in this order: the gap between the caption's last two lines; with one line so far, the gap under `next` when the line after it goes on in `next`'s face and size and is within 1.5 pitch; else the paper's pitch for `next`'s size (the old R7a); no pitch to measure (0) and nothing else: refused.
  `continuesCaption` still holds `next` to `previous`'s size (within 0.6) right after, as before.
- **`continuesCaption(previous, next, pitch, body, furniture, context?)`**: `context = { lines, after? }` is what the caption has shown so far (`lines`, `previous` last) and the line after `next`. The 5-argument call is as before (a caption of the one line `previous`, no line after) so no existing call changes.
- **`captionEnd(read, start, pitch, body, furniture, until?)`** is the one place a caption's extent is read: it walks forward from the opener, building `lines` and `after`. The three callers use it and so agree by construction:
  - the caption loop in `buildOutline` (`rest` is `read.slice(i + 1, end + 1)`);
  - `figureTextOf` (the caption's lines are `taken`);
  - `inCaption` (R6b). It used to walk back from a line, testing each pair; what the caption has shown so far decides whether it goes on, so it now walks back to the nearest line that opens a caption and asks `captionEnd(…, until = reach)` whether the caption runs on to the line asked about (`reach` becomes `j - 1` past an opener that follows open prose, as the old walk continued above it). Same lookback bound (`CAPTION_LOOKBACK`), same answers for the old shapes.
