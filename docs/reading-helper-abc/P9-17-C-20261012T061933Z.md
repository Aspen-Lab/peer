d. **The hand-off asks "is the focus in the window?"**, not "was the control pressed": a touch tap or a mouse press with the focus outside does not pull the focus into the input (no on-screen keyboard). Both ways are pinned.
e. **The unit sweep of the new rule is green by design** (the fourth parameter already generalised the clamp in commit 1); the red-first tests of commit 3 are the flow tests that need the measured height.
