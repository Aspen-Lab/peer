## 2. The three rules, as built

**A, the fold** (`rowsOf`). Every run set below `SCRIPT_RATIO` of the page's usual height is a script, a whitespace-only one included (the `item.str.trim()` test that sent the stored space to `place` is gone). A first pass places the full-size runs only; `ownerOf(script, among)` picks the nearest row of `among` within `−SCRIPT_DROP … +SCRIPT_RISE` by |rise|; `fold` pushes the script and flags it `raised` when it sits more than `SUPERSCRIPT_RISE` above the row. A script with no base row near it is small print: whitespace ones are placed as before, text ones try the rows made so far (small print's own included) and then `place`. The window constants are unchanged (7.5 / 3.5 / 1). No x test.

**B, citation versus exponent** (`CITATION_MARK`, `CITED`, one test in `lineOf`).
`CITATION_MARK = /^\d+(?:[\s,–−-]+\d+)*$/` (still at most 12 characters; the space-separated `89 91` stays valid; a run with its own sign, `−13`, `4−`, `2+`, is never a citation).
`CITED = /(?:[.,;:!?)\]”’"']|\p{L}-|\p{L}{3,}|\p{Lu}\p{Ll}|[\p{L})]\d+)$/u` (punctuation, bracket or quote; a suspended hyphen; a word of three letters or more; a capitalised pair, an element; a formula ending in digits).
The one narrow addition: `RATIO_GROUP = /\([^()\s]*\/[^()\s]*\)$/`. A mark of exactly one digit after such a group is an exponent and stays; `(ABC)`+`12`, `(Figure 2)`+`12` and `(i/imax)`+`12` are still citations. A suspended hyphen is kept as `inter- and` (B §7.6); the join of hyphens at line ends was not touched (P9-09's).

**G, Unicode superscripts** (`SUPERSCRIPT`, `lineOf`). In the kept-run branch, once a raised group is judged an exponent, it is written in `⁰¹²³⁴⁵⁶⁷⁸⁹⁺⁻` when the whole group, trimmed, is made only of `0–9 + − - –` (the three minus marks give one `⁻`), and there is text before it on the line. A group with a letter, a unit, a `.`, a `/` or an inner space (`st`, `2a`, `1/2`, `2.5`, `0−4 μm`) is left as the PDF has it. Lowered runs, the digits set inline in a formula and a raised run at the head of a line are not touched. The optional lowered-label spacing (`f 0-4 μm` against `f4-8 μm`) was **not** done: it needs a rule about a raised space run that stands before a script, which I could not measure on more than one paper in the time; left to a later item.
