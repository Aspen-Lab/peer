## Rules

1. `continuesAcrossPage`: a block that ends with no sentence terminator (`. ? !` with a closing quote or bracket allowed, an `ABBREVIATION_END` stop counted for none) joins the next whatever its first word is. The `CONTINUING_OPENER` / `CONTINUING_WORD` pair is gone.
2. The float rule joins on the same terms (a capital too).
3. A line that opens a heading or a list item is not joined (`HEADING_OR_LIST_OPENER`: a bullet or dash, `1.` / `2)` / `iv.` / `a)` / `IV)`, a numbered heading `3.2 Annealing`, or a line set in capitals alone).
