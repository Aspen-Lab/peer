## The rules as built

1. **The anchor knows where the words are.** `lib/notes/types.ts`: `NoteAnchor` gains `start?` / `end?` (offsets in the paragraph's text, `end` exclusive). `store/notes.ts`: `locatePassage(paragraph, passage)` — the passage's first occurrence, white space in the passage matching any white space in the paragraph (the selection arrives collapsed), formulas (`⟦…⟧`) masked so a match never starts or ends inside TeX; null when not found whole. `addSticky(noteId, { paperId, paragraphId, passage, paragraphText? })` stores `start` / `end` from it; without `paragraphText`, or when the passage is not found whole, the keys are absent (the 09a anchor shape, byte for byte). **What hands the place on:** `selection-toolbar.tsx` is **unchanged** (its `onTakeNote(target)` already carries the paragraph's indices and the passage); the page's `takeNote` is `useTakeNote({ …, body: reading?.body })` (one line in `page.tsx`), and `useTakeNote` / `takeStickyNote` in `sticky-note.tsx` look the paragraph's text up in `body` and pass it as `paragraphText` (two small hunks, `takeStickyNote`'s target type and its `addSticky` call; the sticky's header quote needs nothing new). `anchorMap` (`lib/notes/blocks.ts`, one entry type and its builder) now carries `start` / `end` / `quote` to the body when the anchor has a range.
2. **The highlighter.** `note-tags.tsx`: `passageSegments(text, spots)` cuts a paragraph's text into plain runs, marked ranges and lone tags; `paper-body.tsx`: `NotedText` draws each marked range as `<mark data-note="N" class="bg-[color:var(--color-note-mark)] text-inherit">…</mark>` with the existing clickable `NoteTag` **immediately after it**. Two notes in one paragraph mark their own words, each with its own tag; overlapping: the later mark starts where the earlier ends (no nesting) and its tag follows its own end; a note whose words lie wholly inside earlier marks keeps its tag only, right after that mark; a note with no range, or whose range the text no longer holds, draws no mark and its tag stands at the paragraph's end as before. "No longer holds" is checked, not assumed: the range must lie in the text, be non-empty, cut no formula, and the text in it (white space collapsed) must start with the anchor's quote. With no notes the paragraph renders `MathText` as it did (the old no-anchors test still byte-equal). The mark sits inside the paragraph's `<p>`: the selection listener, the explain route's tints and the plain rewrite are untouched (`readSelection` on a node inside a mark still returns the paragraph's target — tested; measured: the pill stands on a selection inside a mark). **The token:** `--color-note-mark` in the three palette blocks of `globals.css` — light `#fcee9e`, dark `#403a14` (both dark blocks the same).
