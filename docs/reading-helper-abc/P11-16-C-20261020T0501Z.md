2. **The header slot** (`reader-shell.tsx`, `reader-layout.tsx`): `ReaderShell` takes `header?: ReactNode`, drawn after the pin button in the left pane's header row (the button keeps the left edge, the row wraps if the pane is too narrow); the layout passes `<ReadingControls spread />` there.

A reader's stored fold or pin still wins; a first visit writes nothing. `defaultsFit` stays (it states a fact, and its test pins it) but no longer decides the first visit.
5. **The dead spread constants** (`spread.ts`, `spread.test.ts`, `page.tsx` comment lines): `PANEL_CLASS`, `PANEL_STICKY_CLASS`, `PANEL_TAIL_CLASS` and `COLUMN_CLASS` are removed; `SPREAD_GRID`, `PAGE_CLASS` and the caps stay (`loading.tsx` and the error states use them).
