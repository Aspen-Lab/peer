Page 15 likewise has one eligible cluster `[120.79,138.21,499.35,618.19]` and figure 5 typed line `[108,603.20,504.00,612.11]`, original block 109. Both typed lines horizontally overlap their clusters, but their vertical ranges are inside the cluster bounds. The candidate's `captionDistance` returns null for overlap; the drawing therefore lacks an explicit caption and is discarded before same-label competitor resolution. The observed one-eligible-cluster pages have no tie to resolve. This demonstrates the failure path, not why the path bounds extend below the visible panels: page 14 has 54 collected path boxes extending past the caption top and page 15 has 135. Their actual provenance and an independently defensible crop boundary need further measurement.

## Three external candidate experiments — no safe choice yet

The probes change only a private copy of the overlap decision, never repository code. All are counterfactual rules, not recommendations. Invented input has a panel with a connected path extending past a caption; a second invented input puts a typed line just inside a panel; a third puts it deeper inside. The current candidate rejects both the overlapping case and the interior labels.

| Probe | Public 4/5 | Invented overlapping caption | Interior label |
| --- | --- | --- | --- |
| Treat every vertical overlap as distance zero | both returned | returned | near and deep labels wrongly returned |
| Treat overlap within 28 pt of lower region edge as distance zero | both returned | returned | near-edge interior label wrongly returned; deep rejected |
| Treat overlap within 10% of region height as distance zero | both returned | absent | both sampled interior labels rejected |

Each experiment retained expected counts on the sampled existing invented Table veto, genuine same-label tie, above-caption framed multipanel, and two-column cases. This is a small subset, not a full test run or proof of safety. The numerical probes are not proposed thresholds. In particular, the first two demonstrate false attachment, while the third misses the analogue. None establishes complete captions or safe cropping.

A C implementation is not yet justified. The finite next measurement is to trace the path boxes that extend into the caption on pages 14/15 and compare their actual rendered footprint and provenance against an invented example containing a true interior typed label and a nearby Table. Determine whether there is a general observable boundary that separates panel content, caption and background without grouping unrelated regions. Independently measure the two-panel image geometry of figure 2 and ambiguity on analogous unrelated adjacent images; do not lower floors or automatically merge them. If no defensible boundary exists, preserve the honest fallback and record the ambiguity.

Any future C guide must target `web/src/lib/figures/pdf-engine.ts` and its caption-pairing tests, cover below/above/two-column/multipanel positives, nearby Table veto, same-label ties, full source text, clipped-caption boundaries, unchanged resource budgets and derived-cache freshness. Do not use these observations to change source classification, widen matching, cross pages, remove ambiguity, or claim source-complete crop coverage. Manager must independently verify normal UI and whole-source panels.
