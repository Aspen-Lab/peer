This section replaces the in-progress checkpoint only. Earlier results and the three overlap-rule experiments remain unchanged. The new work uses the same source identities, public bytes and Node 22.23.4; it adds no UI, upload, dependency, product change or full test run.

**Observed mechanism.** On page 14, all 54 collected fill-path boxes that extend beyond the typed caption's top are subject to four nested path clips. Their effective clip bounding-box intersection ends at y=603.954, while the typed line starts at y=615.082. On page 15, all 135 such boxes are fills under four nested path clips whose effective intersection ends at y=592.071, while the typed line starts at y=603.199. In representative offending paths, the transform matrices are `[1.255,0,0,-1.255,108,603.954]` and `[1.245,0,0,-1.245,108,592.071]`. An additional clipped-stroke counterexample uses the 40 pt rectangle but a 10 pt wide clip at x=80–90, wholly outside the left centerline edge at x=100. It paints 8,000 sampled pixels in `[80,100,90,300]`. Intersecting the *centerline box* with the clip would erase all of this real support; the unmodified candidate instead returns its unclipped large centerline crop, which also excludes the strip. The prototype correctly observes a narrow support region that does not pass the existing size floors. This case shows why a stroke cannot be discarded merely because its centerline misses a clip.

A separate 119 × 180 pt centerline rectangle with 8 pt stroke has actual pixel box `[96,96,223,284]`, 127 × 188 pt. The centerline candidate returns nothing because the 119 pt width is below the unchanged 120 pt floor; the native-support prototype returns a figure. Keeping the numerical floor constants while changing which rectangle they apply to changes eligibility and must be an explicit design decision with regression cases, not described as unchanged behavior.

**Comparison of representations.** Keeping the established centerline box for clustering and the reported region can preserve existing thin-stroke exact-region assertions, but the measured thick, miter and transformed cases show that rendering only that region plus 10 pt does not preserve all visible stroke pixels. A second support representation must therefore affect actual rendering when its painted support exceeds that clip, or the system must retain a safe absence; merely tracking support for veto and eligibility is insufficient. Conversely, using MuPDF's conservative native box everywhere expands thin output and, in the acute example, treats unpainted space as though it were occupied, suppressing a figure whose real stroke is separated from its caption. A single conservative rectangular support bound is an upper bound, not proof that its entire interior is painted. Clipping its bounding rectangle can remove invisible overhang safely only to the degree that the clipping state and stroke bound are correctly represented; it cannot establish that a nonrectangular clip paints all points in the intersected rectangle.

A safe general choice is not established here. A C experiment must retain measured genuine strokes and use explicit tests for both false positives and false absences. At minimum: retain the existing 0.8 pt output box and complete output, separately test 40 pt and transformed strokes extending beyond old padding, the acute miter with a nonoverlapping caption, the true stroke/caption intersection, and a clip containing visible stroke but no centerline. Check eligibility at the exact floor boundary; do not weaken the old box assertions or silently reclassify 119 pt centerlines. Run below/above caption, genuine ambiguity, Table veto and complete source text guards. For each returned candidate compare rendered pixels with the page's corresponding painted support, and verify page-edge clipping, padding, scale rounding, timeout and pixel-budget behavior. If conservative support alone cannot decide a caption relation or fit within budgets, report uncertainty or a safe absence rather than asserting an exact intersection. Any extra support tracking must preserve bounded work, the 12,000 drawing-rectangle ceiling, 25 s budget, 4.5 megapixel render ceiling, and cache freshness. This does not select a new threshold, change the published floors, or authorize a product mutation.
