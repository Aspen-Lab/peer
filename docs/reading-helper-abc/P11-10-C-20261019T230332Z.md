## What each rule is

**Rule 1, the contract.** `pane-layout.ts` holds the constants of B §2.2 and the pure `fitPanes`, `clampPane`, `stepPane` (with `paneRange`, `defaultPanePx`, `defaultsFit`). `stepPane` and `clampPane` take the pane first and an optional `room` (the window and the other pane's track, so the centre keeps 440); `fitPanes({ viewport, left, margin, leftPinned })` returns `{ left, leftTrack, margin, centre, pinned, forced }`. The margin has no collapsed flag anywhere (a test reads the source for one). `store/reader-panes.ts` is `peer-reader-panes` v1, `skipHydration`, `leftPinned? leftWidth? marginWidth?`; a corrupt blob reads as the defaults, widths clamped on read. `lib/reader/margin.ts` is `MARGIN_SELECTOR`, `MARGIN_CARD_SELECTOR`, `MarginRect`, `registerMargin(el)`, `useMarginRect()` (null without a shell), `placeInMargin`, plus `readPageZoom`, `marginRectOf`, `useMarginStore`. The rect is the cell's left/width and the band `DOCK_TOP_PX` to `columnBottomPx(innerHeight, legendHeightPx(zoom))`; it is re-read on a ResizeObserver over the cell, **its grid** (a scrollbar that appears moves the cell without resizing it) and the zoom root, and on resize. A test pins `DOCK_MIN_VIEWPORT_PX === SHELL_MIN_VIEWPORT_PX`.

**Rule 2, the divider.** `role="separator"` with the three aria values; the lightbox's capture pattern with a 4 px threshold; the delta divided by `--page-zoom`; the CSS variable written once per frame; the store written on release only (a cancelled pointer puts the pane back); arrows ±16, Shift ±64, Home, End, Enter; a chord (Alt, Ctrl, Cmd) is left to the browser; a double-click is the default.

**Rule 3, the shell.** `ReaderShell({ left: { fixed, scroll } | { whole }, centre })`; the grid `var(--left-w) 12px minmax(0,1fr) 12px var(--margin-w)`; the left pane in three states on one node, `inert` while hidden; peek after 150 ms on the rail, closed 250 ms after leaving, on Escape or on a press outside, kept open by focus inside; a press pins; the first visit is pinned from 1144 css px, else the rail; the empty `<aside data-reader-margin aria-label="Margin">` registers its rect; the centre's content `max-width: 38em`, centred, the prose measures lifted inside it. `SPREAD_QUERY` is `(min-width: 64rem)`. `fitZoom`'s reference is 320 + 640 × step + 360 + 24 (1344 at 1x). `page-container.tsx` has a `reader` width (760 px below 1024, full-bleed from it, `lg:pt-4`). `globals.css`: the pane rule replaces `reader-panel`, and `.peer-main-content:has([data-reader-shell]) { padding-right: 0 }`.

2. **For C3 (P11-16).** Slots: `left={{ fixed, scroll }}` or `{{ whole }}`, `centre`; data attributes `data-reader-left`, `-left-fixed`, `-left-scroll`; the pane's header row (the pin button, ~36 px) stands above `fixed`, so the reading controls can go in `fixed`. The pane has `padding-inline: 16px 8px`.
