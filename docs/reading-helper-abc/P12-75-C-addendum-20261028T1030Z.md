## The rules as built

**2.1.** In `canonicalizeHeading`, before the L1 methods line and so before `^experiment…`: `^experimental(?:\s+(?:section|part|details?|procedures?))?$` on the heading with its number stripped is `methods`. Only the bare form and "Experimental part" change (the others were methods already). "Experiments", "Experiment", "Experimental results", "Experimental evaluation", "findings", "validation", "data" and "Experimental and numerical results" stay results (negatives, one test row each). In the outline, "Experimental" or "Experimental part" with only sub-headings under it is a methods group row with methods children at level 2; "Experiments" with sub-headings is no group, as before.

**2.2.** `flush` computes `partName` (the heading's own words against `PART_NAME`) once. A heading that is a part name cannot take the open group's bucket at level 2: it ends the group and is its own row (a normal row if it has text; a new group row if it is empty and has sub-headings under it). Descriptive headings set smaller are children as before.
