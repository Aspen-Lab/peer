## 2. The rules, as built

1. **No markup visible.** A block being edited is a `contentEditable` `Surface` (`wysiwyg-field.tsx`) drawn by `mountInline(treeOf(source))`: `<strong> <em> <u> <mark> <code>`, a citation / `[[note]]` / link as a non-editable chip (`contenteditable=false`, `data-src`). Tests: for 25 sources the surface's `textContent` is `plainInline(source)`. A code block keeps a textarea (nothing in it is markup).
2. **Lossless back.** `serializeInline(root)` = `readTree` + `serializeTree`: `serializeInline(render(src)) === src` for 25 sources (every mark, nested, adjacent, chips, newlines). Pinned: a character typed inside a bold word stays bold; **at a mark's edge the character joins the mark at its END and does not at its START** (the caret takes the format of the character before it); an empty mark is dropped; edge spaces typed inside a mark are written outside (`**alpha **` never stored); a mark never spans a line break; underline is written across whole words; a mark the dialect cannot read back is left unwritten, never shown; a seeded walk of 800 edits leaves no stray delimiter (`strayCount` ≤ before) and the source is a fixed point. The store gets the source on the same 500-ms debounce; a block is drawn again only when its text is not what the surface last wrote.
3. **Keys and toolbar act on the selected words.** DOM selection → plain (visible-character) offsets → `markSource` (`markEdit`) → block redrawn → selection restored by plain offsets over the same words. `alpha beta gamma`, "beta": Ctrl/⌘ B → `alpha **beta** gamma`; Ctrl/⌘ U → **`alpha __**beta**__ gamma`** (P10-13's nesting); Ctrl/⌘ Shift H → `alpha ==__**beta**__== gamma`; selection "beta" after each. **A mark key with nothing selected (or only spaces) toggles the mark for what is typed next** — pinned: `pressMark` → `pending`; the next typed character is written by the editor (`insertMarked`) wearing the marks; moving the caret drops it. A delimiter typed as characters (`*italic*`, `==hi==`) is read as a mark when it closes (Notion-like) and what follows is outside it.
4. **Undo / caret.** A stack of sources per block (`recordState` / `stepBack` / `stepForward`: a run of typing is one step, a pause > 1 s, a mark, a menu pick is a step; 200 deep; each step gives back the selection it was left with), not the browser's (it cannot follow a surface that is drawn again; `historyUndo` is cancelled); ⌘Z, ⌘⇧Z, ⌘Y. The 500-ms save never touches the caret (no redraw when the source is the surface's own). Enter at the end makes the next block; in the middle `splitSource` cuts the words with the marks closed on each side (`**al**` / `**pha**`); at the start a block above; Backspace at the start joins with the marks merged (`joinSources`). Shift+Enter is a line break in the block.
5. **Surfaces.** The notes window and the notes page mount `NoteEditor` (verified in Chromium). **The sticky window does NOT mount `NoteEditor`**: it has its own `<textarea>` (P10-09a) and shows `**` raw. I built `WysiwygField` (same surface, same keys, Enter = line break; tested in Chromium as the sticky window) and left `sticky-note.tsx` / `sticky-note.test.tsx` untouched: `P10-16-sticky-carry.patch` (`git apply`, 83 lines; sticky tests 34/34 and the other notes tests green with it) is for the manager to carry. `.txt` / Copy / `.doc` / print show the final look (checked: `.txt` `alpha beta gamma delta see (A Survey of Shore) end`, `.doc` `<mark…><u><b>beta</b></u></mark>`); **the `.md` export keeps the marks — Markdown is the format** (`alpha ==__**beta**__== gamma delta see [@survey] end`).
