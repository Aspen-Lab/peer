## Rule 1 — the passage is the paragraph's words
- Which marker: the existing structure, not a new attribute. A tag (`NoteTag`) is a `<sup>` (word joiner U+2060, then the button "[n]"); the paper's own paragraph holds no `<sup>` (a formula is a drawn `.katex`, which the reading refuses), so a `SUP` in the range's contents is a tag. `data-note-tag` would need `note-tags.tsx`, which is not this item's file.
- `paper-body.tsx`: `readSelection` reads the words from the cloned range's text nodes outside every `<sup>` (`wordsWithoutTags`; null when the contents hold no tag or cannot be walked, and `selection.toString()` is then the words as before). The triple-click `\n` check still reads `toString()`. The passage, the target and `sameSelection` therefore never hold a tag.
- `store/notes.ts`: `stripTagText(passage)` removes a tag (U+2060 + `[n]`) and any stray joiner — a "[12]" with no joiner before it is the paper's own citation and stays. `locatePassage` searches the stripped words; `addSticky` stores the stripped passage as the quote and locates the range from it.
- `sticky-note.tsx`: the header quote is `quoteHead(stripTagText(quote))` (an older note stored with a tag reads clean too); `takeStickyNote` hands `stripTagText(target.passage)`.
- A selection across a tag anchors to the words on both sides; the note draws as P10-20's nesting (it holds the earlier mark) or overlap case (the later mark starts where the earlier ends) — `passageSegments` unchanged.
