**Outline (they decide whether a part has a row at all)**

Scratch what-if (largest size holding ≥ 35 % of the heaviest size's characters): 11 sections.
- **O2. ## 5. Three candidate Tier-0 rule sets

All three include the **lexical base** (not inference; the heading names a role): L1 `experimental methods` filed as methods before `:192`; L2 end-matter words (online content, additional information, reporting summary, peer review information, reprints, keywords) added to the apparatus words. All three apply **only to a row whose heading names no role** (a named bucket is never overridden) and **only when an introduction is anchored** (named, or front text); a paper with one big unheaded section is left to the model partition. The evaluation below is on the **repaired-outline rows** (section 4 repairs, scratch oracle); "today's rows" would add the outline failures of section 3.

### Rule set A — anchors (position only; row level)

1. Front text: text before the first heading, in a paper that names no introduction, is the introduction (setup).
2. Unnamed top-level rows between the introduction and the first named method / discussion / conclusion / back-matter row are results (evidence); an unnamed row directly before a references row is back matter (apparatus).
3. Unnamed top-level rows after a references row are apparatus; an unnamed row right after a named method or apparatus row continues it.
4. Sub-rows take their part's role.

### Rule set B — A plus the paper's own signposting (paragraph level)

A, and: **the closing split.** In a paper that names no discussion / conclusion row, look in the last 4 paragraphs of the last results row for one that has (a) a summary cue ("we show / demonstrate / conclude", "in summary", "taken together", "our findings", "overall"), (b) no figure or table reference, (c) at least 20 % of its long words in the abstract's; the row is split there and the tail becomes a row (interpretation) with the role's own label as its heading. Unheaded introduction confirmed by an announcement ("here, we…", "in this work…"; confidence only). Uses the existing virtual-row machinery of the model partition (`reading-partition.ts`, `partitionedMap`: a row replaced by rows over paragraph ranges, the body untouched, §1h.79 (c)).

### Rule set C — A plus a content score for the unnamed parts

A's positions, but between the anchors each unnamed row is scored on counts per 100 words (figure references; procedural passives such as "was performed / were synthesized"; hedges; first person) and labelled method when procedural wording ≥ 1.0 and figure references < 1.0, interpretation when hedged and first-person with no figures, else evidence; plus B's closing split.
