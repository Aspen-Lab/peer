## Files changed (all new)

- `web/src/test-support/hook-runtime.ts`
  - A minimal hook runtime adapted from A's P0-04 probe `p3-hooks`, with no dependency.
  - It provides `useState`, `useMemo`, `useCallback`, `useRef`, `useEffect` and `useLayoutEffect`.
  - `mount(hook)` works like opening a page: it renders, runs the effects, lets their promises and timers settle (5 macrotask ticks), and re-renders after a state change until nothing changes (at most 30 rounds). It returns `{ value, unmount }`.

  - It imports nothing (not React, not Vitest), so `tsc`, lint and the build treat it as plain TypeScript.
