## The rules

1. **A sticky's heading is whole (BACKLOG-90).** Delete at the end of the block before an anchored `h3` does not join it, and Delete at the end of the anchored heading does not pull the next block's words into it; Duplicate on an anchored block copies the words without the anchor (one note, one mark); the toolbar's heading / list buttons are disabled (`aria-disabled`, greyed) while the caret is in an anchored heading; an anchored block that is not an `h3` (left by the old Backspace before P10-25) is read as a note heading again (repaired to `h3` on load, the anchor kept). Tests.
2. **A mark keeps the selection (BACKLOG-79).** After bold / italic / underline / highlight is applied to a selection, the same words stay selected, so a second mark key adds a second mark to them; never an empty `****` / `====` / `____` pair written to the source. A test on the key path (two marks in a row → `***x***` or `==**x**==`, no empty pair).
3. **Undo covers a block split and a join (BACKLOG-85).** Enter in the middle of a block and Backspace joining two blocks each push one undo entry; Ctrl/⌘ Z restores the blocks as they were (text, type, anchor, checked, indent). Tests.
4. **A literal mark character inside its own mark (BACKLOG-85).** A `*` typed inside bold (an `_` inside underline, an `=` inside highlight) is written escaped (`\*`) and shown as the character in place, and the serializer round-trips it; tests in `wysiwyg.test.ts`. Underline covering whole words and the IME note stay recorded, not changed.
5. **Nothing else changes**: P10-25's anchored-heading rules, the hidden title block, the exports.
