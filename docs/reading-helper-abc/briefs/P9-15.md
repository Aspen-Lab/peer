## The rule (the island writer; before `joinProse`)

Within a display island, the **base row** is the text-size row that holds `=` (else the widest text-size row). Every other row of the island is placed by its x-span against the base row: a row **above** the base whose x-span overlaps a row **below** the base (both within 1.2 × leading of the base line) forms a **stack** at that span: `<above> / <below>`; a stack is inserted into the base row's text **at the gap** whose x-range covers the stack's span (between the base run ending before the span and the one starting after it). A multi-run numerator or denominator is parenthesised: `(1/N Σn I(hkl)/I₀(hkl))`. A short script-size row (≤ 3 characters) directly below or above an operator run (`Σ`, `∑`, `∏`, `∫`, `lim`) within the same span is that operator's **limit** and is written right after it (`Σn`); with no operator run in the text layer the limit is written before the row it stands under (`n I(hkl)` → keep as `n I(hkl)`, say so). A row with no partner across the base line and no operator is left where today's writer puts it (after the base row). The island then reads on one line: `PF(hkl) = I(hkl) / n I(hkl) × 100` (or `… / Σn I(hkl) × 100` with the sign) and `TC(hkl) = I(hkl)/I₀(hkl) / (1/N Σn I(hkl)/I₀(hkl))` (P9-14's subscripts if landed, else `I0`).
