## The rules

1. **A mark over a marked range nests, never splits.** `markEdit` applied to a selection that lies inside, equals, or exactly covers an existing mark of another kind wraps the whole (`__alpha__` + highlight → `==__alpha__==`); applied to a range already carrying the same mark it removes that mark (toggle, as the toolbar documents); applied across a mark's boundary it extends the selection to the mark's edges first (never leaves an unmatched `__` or `==`); after every edit the source parses with no stray delimiter (a property test over the four marks × inside / equal / across / partial, each asserting the parse has no `text` token holding a lone `__` or `==`).
2. **The marks survive an export**: `plainText` drops every delimiter, nested too (`==__alpha__==` → `alpha`); the parse of a nested mark renders both (a `<mark>` holding a `<u>`); a test each.
3. **Nothing else changes**: the toolbar's buttons and keys, the blocks, the editor's caret handling beyond the selection extension of rule 1.
