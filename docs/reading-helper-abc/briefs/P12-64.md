## The rules

1. **A title size.** Each line also carries a character-weighted size (its runs' sizes weighted by their characters); `titleOf` ranks page-1 lines by it, so one oversized letter (a drop cap) no longer lifts a body line.
2. **The embedded title as a witness.** When the PDF's Info or XMP title is present and plausible (3+ words, not a file name, not the journal name), `titleOf` picks the page-1 size class whose text matches it best; with no witness, the largest class by the title size, excluding a masthead (a line repeated in the running heads, or above the title block in a size class of fewer than 3 words that matches no witness).
3. Nothing else changes: `size`, headings, the outline's sections.
