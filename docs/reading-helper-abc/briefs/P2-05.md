# P2-05 — the answers in the Markdown export and the reading note

Role: C. Ruling §1g.6 (and §1g.3 for the shapes, §1b for verbatim quoting). Acceptance §3d 12.

Setup: `git pull --ff-only origin deep-report-reading-helper-enhancement`; read §1g.6, §3d 12, `lib/papers/reading-markdown.ts` (`readingToMarkdown`: the frontmatter and the block order, where the Decision block's content lands), `lib/notes/templates.ts` (`readingNote`), `lib/papers/report.ts` (`QuestionAnswers`, `ReadNextItem`, `Claim`), `components/reader/copy.ts` (`ANSWERS`, from P2-04 — the export uses the same words), `components/reader/for-your-questions.tsx` (P2-04 — the same order), `app/papers/[id]/page.tsx` (the `copy` action that calls `readingToMarkdown`, and wherever `readingNote` is called).

What to build:

1. **Markdown export** (`reading-markdown.ts`): when the report carries `forYourQuestions`, a "For your questions" block renders after the Decision block's position and before "What it proposes", in the page's order and words: per question a line with the question, the verdict line (`ANSWERS.answered` / `ANSWERS.partly` / the exact `ANSWERS.notAddressed(q)` sentence), each answer's `text` followed by its `evidence` as a quoted line (`> …` with the section heading and `p.N` when known, in the form the existing evidence quotes use in this file), and "Read next" lines `§Heading · p.N · M min — why` with `background` marked as the page marks it. The frontmatter gains `questions:` as a YAML list of the request's questions when at least one exists, and omits the key otherwise. A report without `forYourQuestions` exports byte-identically to today (test against an existing fixture).
2. **The reading note** (`notes/templates.ts`): `readingNote(paper, { questions, forYourQuestions })` adds a section "My questions → what it said" only when `questions` is non-empty: one entry per question with the verdict and the quoted evidence per answer (same words as the export). Without questions the note is byte-identical to today.
3. **The page**: the `copy` action and the note creation pass the settled questions (`settledQuestions(asked)`, never the gist) and `model.report`; nothing else on the page changes.
4. **Tests**: the export with a report carrying two questions (one answered with two answers, one `not_addressed` with a background `readNext`) — the block's position, every string, the quoted evidence verbatim, the frontmatter list; without questions byte-identical to the current fixture output; the note with and without questions; the page's copy call passes the settled questions (a pure helper test if the page cannot mount).

Rules: the paper's words only as verbatim quotes; no question text in any log line; commit only your files; the four gates; checkpoint `docs/reading-helper-abc/P2-05-C-<UTC>.md`; commit `feat(reader): the reader's questions and answers in the Markdown export and the reading note (P2-05)`; push; one-paragraph report.
