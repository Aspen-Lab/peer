## The rules

1. **L1.** `experimental methods` / `experimental procedures` / `experimental` + a methods word is filed as **methods**, before the `^experiment…` → results rule. Cases in `html-text.test.ts`.
2. **L2.** End-matter notes are apparatus: online content, additional information, reporting summary, peer review information, reprints and permissions, data availability / code availability (if not already), author contributions, competing interests, keywords. Use an existing apparatus bucket where one fits; a new bucket only if needed, mapped to apparatus in `ROLE`.
3. **Rules A1–A4 in `reading-roles.ts`**, a pure function over the map's rows called once from `readingMapOf` (so the map, the route weights, the gist tiers and explain read the same roles). They apply **only to a row whose heading names no role** (`body`) — a named bucket is never overridden — and **only when an introduction is anchored** (a named introduction, or the front text of A1); a paper that is one large unheaded section is left alone (the model partition's case).
   - **A1.** The front text (the first section with no heading, per the interface above) in a paper that names no introduction is **setup**, labelled with the role's own label (the label the model partition's rows already use for this role).
   - **A2.** Unnamed top-level rows between the introduction and the first named method / discussion / conclusion / back-matter row are **evidence**; an unnamed row directly before a references row is **apparatus**.
   - **A3.** Unnamed top-level rows after a references row are **apparatus**; an unnamed row right after a named method or apparatus row continues that role.
   - **A4.** Sub-rows take their part's role.
4. **The closing split (rule set B).** In a paper that names **no** discussion / conclusion row, look in the last 4 paragraphs of the last evidence row for the first paragraph that has (a) a summary cue (we show / demonstrate / conclude, in summary, taken together, our findings, overall, in conclusion), (b) no figure or table reference, and (c) at least 20 % of its long words (7+ letters) among the abstract's long words; split the row there with the partition's virtual-row machinery (rows over paragraph ranges, the body untouched) — the tail is a row with role **interpretation** and the role's own label. No abstract → no split. Skipped when a discussion or conclusion is named.
5. **No mark** (§1h.424 (a)): an inferred role is shown exactly like a named one. The model partition's existing "Peer's reading" tag on its own rows is unchanged.
