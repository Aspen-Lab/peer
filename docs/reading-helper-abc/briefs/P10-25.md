## The rules

1. **An anchored heading keeps its type.** Backspace at the start of a block that carries an `anchor` does nothing (as at a note's first block); the type menu does not offer a type change for it; Delete at the end of the block before it does not join it; the heading's text may still be edited (a reader may rename "Note 2" — the anchor and the number `n` stay; say whether the paper's tag reads `n` or the heading's words — it reads `n`, pinned). Tests in `note-editor.hidden.test.ts`'s style (source-regex where no DOM runtime) plus a fake-DOM test on the key handler if P10-16's `test-support/fake-dom.ts` reaches it.
2. **Undo restores a block's type and anchor**: the undo stack keeps a block's `type` and `anchor` with its source, so Ctrl/⌘ Z after any type change (where one is allowed) brings both back; a test.
3. **Nothing else changes**: the WYSIWYG surface, the hidden title block (P10-23), the stickies' numbering, the exports.
