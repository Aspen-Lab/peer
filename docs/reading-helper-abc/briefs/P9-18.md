## The rule (A §6.1, ruled §1h.56)

Offer a selection when the primary pointer is up. In `useSelectionListener` keep a flag `down`: set on `pointerdown` (document, capture) when `event.isPrimary && event.button === 0 && event.pointerType !== "touch"` (touch selection is made with handles that fire no pointer events, or `pointercancel`, and keeps the debounce), and clear the pending timer then; `selectionchange` arms the 150 ms timer only while `down` is false; on `pointerup` and `pointercancel` (document, capture) and on window `blur` clear the flag and arm one read with delay 0 (the last `selectionchange` of a drag arrived before the release, so nothing else will schedule it); a click that collapses a selection reports `null` the same way. Keyboard selection (shift + arrows) and programmatic changes keep the 150 ms. Upstream `sameSelection` goes on dropping duplicates. Every listener added is removed in the hook's cleanup (A found every existing one clean — keep it so).
