## The rules

1. **A bound figure of a PDF is its route URL**: where the bound caption has a `page` and its label names a picture number ("Figure N" / "Fig. N"), the section's `figureImageUrl` is `pdfFigureUrl(paperId, page, N)` — whatever the pool would have given (a `data:` URL today). The paper's id reaches `bindFiguresToReport` from the route (both call sites); where there is no id, no page, or the label is not a picture number ("Figure S3", "Table 1"), today's behaviour stays (the pool's URL, or none).
2. **An HTML source's own image URL stays** (`ExtractedFigureCaption.imageUrl`, absolute): only a figure the pool would have rendered from a PDF changes.
3. **The figure drawn is the same figure**: the route's region for (page, N) is the region the pool would have drawn for that caption — show it on an invented two-figure PDF (both URLs answer 200 `image/png`, and each is the figure its caption names), or say where they can differ.
4. Nothing else in the report changes: labels, captions, sources, the order, the upload's owner-only rule (the route already enforces it; the report stream must not carry the upload's bytes any more than before).
