## The rules

1. **No markup is ever visible.** The block being edited is a `contentEditable` element (one per block, where the textarea is today; `spellcheck` as the textarea had) rendering `parseInline(source)` as `<strong>`, `<em>`, `<u>`, `<mark>`, `<code>`, with a citation and a wiki link as the read view shows them (a non-editable chip, `contenteditable="false"`, carrying its source); the source's delimiters are in no text node. A reader who types, deletes, pastes (plain text only — HTML pasted is reduced to its text), splits with Enter or joins with Backspace sees only words. Test (jsdom): for every mark, nested marks, a citation and a wiki link, the rendered text content equals `plainInline(source)`.
2. **The DOM serialises back to the source, losslessly.** `serializeInline(root)` walks the edited DOM and writes the stored syntax (`**`, `*`, `__`, `==`, backticks; a chip writes its source); round-trip tests: `serializeInline(render(src)) === src` for every mark, nested, adjacent, with a chip, and with an edit (a character typed inside a `<strong>` stays bold; typed at a mark's edge — say which side joins the mark and pin it); an empty mark left by a deletion is dropped; the stored source after every input has no stray delimiter (`strayCount` 0 — reuse P10-13's check). The store receives the source as today (the same debounce; the same `reconcileWindow` / `stickyFollowText` paths — an outside change re-renders the block only when it is not the focused one, else merges as P10-09c does).
3. **The toolbar and the keys act on the selected words.** The DOM selection is mapped to source offsets (each text node carries its source range from the render; a selection inside a chip is the chip), `markEdit` (P10-13) applies, the block re-renders, and **the selection is restored over the same words** (BACKLOG-79: the words stay selected after a mark, so a second key marks them too); a collapsed caret with no selection: the mark key toggles the mark for what is typed next (say how, or say it does nothing — one of the two, pinned). Tests: Ctrl/⌘ B over "beta" in "alpha beta gamma" → source `alpha **beta** gamma`, the selection still over "beta"; then Ctrl/⌘ U → `alpha __**beta**__ gamma` (or the nesting P10-13 fixes — say which); the toggle off.
4. **Undo and the caret.** Ctrl/⌘ Z after a typed word restores it (the browser's undo in a `contentEditable` or a small undo stack of sources per block — say which; a test on the stack if it is yours); the caret stays where the reader put it across the store's save (the 500-ms write never moves it); Enter at the end makes the next block as today, in the middle splits the words as today; Backspace at the start joins as today.
