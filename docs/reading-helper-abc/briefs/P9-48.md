## The rules

1. **No figure by value in the cache.** A report is cached with every `data:` URL replaced by something small that draws the same picture on a reload: the figure-image route's URL when the figure is a page figure of the paper (preferred: say whether the server can send the route URL in the first place, so the browser never holds the data URL at all), else the field dropped (the plate then draws what it draws with no figure — say what that is). A reload of a cached report draws the same picture it drew before the reload, or says why it cannot.
2. **The cache has a character budget**, not only a count: before a write, evict the oldest entries until the cache's serialized size plus the new entry is under a stated budget (≤ 1.5 M characters, named as a constant with its reason); an entry that alone exceeds the budget is not cached (and that is logged as a count, never its text). The quota error is no longer the only thing between the cache and the rest of the origin's storage.
3. **Nothing else changes**: the cache key, the entry's shape apart from the figure, the TTL if any, the reader's key never in the cache.
