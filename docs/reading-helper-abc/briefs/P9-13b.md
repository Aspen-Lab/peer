## The defects, as round 2 renders them (counts from `scratchpad/p9/r2/whole.txt`, scratch — never commit it)

1. **The overbar of a Miller index is a run of its own** (U+0305 COMBINING OVERLINE after a digit), and a space is put after it when the next run starts past the gap threshold: `R3̅ m` (the space group; twice) beside `R3̅m` (once, right); `(11̅ 04)[1̅ 1̅ 20]`, `(11̅ 00)`, `(12̅ 10)` beside `(12̅10)`, `(101̅ 1)` beside `(101̅1)`, `{12̅ 10}crystal1`. About 12 places in 7 paragraphs and captions. Rule: a run that is only combining marks (U+0300–U+036F, U+20D0–U+20FF) attaches to the glyph before it and takes **no space on either side**, whatever the gap: `R3̅m`, `(11̅04)[1̅1̅20]`, `(12̅10)`.
2. **A lowered label after a one-letter variable**: `f 0-4 μm = 0.191, f4-8 μm = 0.212, f 8-15 μm = 0.597` (the space before the label depends on a 0.15-pt gap run), `farea = 0.61`, `jlimiting`, `TH = 0.31`, `RCT`, `Eg`, `A1g`, `Dw`, `ton` / `toff`. Rule: a lowered (or, for the f labels, raised-but-label) run right after a **single-letter** variable run — the two runs touching (gap under 1.5 pt) — is written: **letters only, up to 3 characters → joined plain** (`RCT`, `TH`, `Eg`, `Dw`, `A1g` stays as it is); **otherwise → `var(label)`** with no space before the parenthesis: `f(0-4 μm) = 0.191, f(4-8 μm) = 0.212, f(8-15 μm) = 0.597`, `f(area) = 0.61`, `j(limiting)`, `t(on)` / `t(off)`. A lowered run after a word of two or more letters, or after a digit, is left as today.
3. **A stray space before a subscript's parenthesis**: `I0 (hkl)` (§4.5's explanation line: the `0` is a lowered run, the `(hkl)` follows with a gap). Rule: after a lowered or raised run, a following run that opens with `(` joins with no space.
