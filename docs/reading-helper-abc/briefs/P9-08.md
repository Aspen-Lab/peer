## The three rules (B §2.4, §3.2, §4; ship A and B together — B §0 item 1)

1. **Cluster A — the fold.** In `rowsOf`, a script-size run — **a whitespace-only run included** (today `item.str.trim()` at l.375 sends the space the PDF stores after a citation or an exponent to `place`, which opens a phantom row at the script's baseline that the script then folds into at distance 0) — joins the nearest **text** row within its window (`−SCRIPT_DROP … +SCRIPT_RISE`); only a script with no text row near it (a footer, a note, small print) is placed as before. B's sketch (§2.4, the conservative form measured as `v1`): first pass full-size runs only; `ownerOf(script, baseRows)` picks the nearest base row by |rise|; `fold` pushes it and flags `raised` when `rise > SUPERSCRIPT_RISE`; scripts with no base row: whitespace ones placed as before, text ones try `rows` (the rows made so far, small print included) then `place`. Keep the window constants (B §7.10: the highest script on the owner's paper sits at +7.25 of 7.5 — do not lower them). Direction needs no x test (B §2.3).
2. **Cluster B — citation vs exponent.** `CITATION_MARK = /^\d+(?:[\s,–−-]+\d+)*$/` (at most 12 characters; the space-separated range `89 91` must stay valid — `pdf-outline.columns.test.ts` pins it; never a run carrying its own sign such as `−13`, `4−`, `2+`); `CITED = /(?:[.,;:!?)\]”’"']|\p{L}-|\p{L}{3,}|\p{Lu}\p{Ll}|[\p{L})]\d+)$/u` — punctuation / bracket / quote, a suspended hyphen (`intra-`, `morphology-`), a word of three letters or more, a capitalised pair (an element: `Li`, `Zn`), a formula ending in digits (`NaCoO2`, `Bi2Te3`). An exponent otherwise: after a digit (`10`), a one-letter variable (`R`), one or two lower-case letters (`cm`, `mA/cm`, `s`), or a run with its own sign. **One narrow addition** (B §3.2's known limit, §7.8): a single raised digit after a closing parenthesis whose group contains `/` and no space (`(j/jmax)` + `2`) is an exponent and stays; `(LCO)` + `12` and `(Figure 2)` + `12` are still citations. Cases to pin (invented fixtures shaped like these): drop — `word-`+`2`, `intra-`+`5,6`, `”`+`16`, `Li`+`30`, `Zn`+`24`, `NaCoO2`+`35`, `Bi2Te3`+`52`, every row of the existing P7-11 table; keep — `cm`+`2`, `mA/cm`+`2`, `R`+`2`, `10`+`12`, `cm`+`−1`, `Co(OH)6`+`4−`, `[Co`+`2+`, `OH`+`−`, `MPam`+`1/2`, `st` / `th`, `(j/jmax)`+`2`. A suspended hyphen is kept as `intra- and` (B §7.6) — the join of hyphens at line ends is P9-09's, not yours.
3. **Cluster G — Unicode superscripts.** In `lineOf`'s kept-run branch (B §4's sketch, ~l.428): a **whole** adjacent raised run whose every character is a digit or a sign (`0–9`, `+`, `−`, `-`, `–`) is written in Unicode superscripts (`⁰¹²³⁴⁵⁶⁷⁸⁹⁺⁻`); any raised run with a letter, a unit, `.` or `/` is left exactly as it is; lowered runs and inline digits (`H2O`, `LiCoO2`, `TC101` — no geometry, B §4) are not touched; **no conversion for a raised run at the head of a line** (keeps "keeps a number at the head of a line …" green).
