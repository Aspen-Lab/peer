## Path and competing rules

`readPageStructure` normalizes joined structured lines into one block bbox, sorts y then x. `captionDistance` measures below/above/overlap; baseline adds a 40 nonoverlap penalty and above 30, chooses any explicit Figure over generic, then `mergeCaptionLines` takes subsequent sorted blocks up to 28pt/20% horizontal overlap and 500 chars, stopping on first mismatch. Raster size gates admit generic/no caption; vector clusters require explicit. Drawing overflow skips vector analysis; candidate sorting and >=0.85 overlap dedup precede rendering. Baseline `readPage` filters requested caption key then fills room in page order; per-page/page-count, byte/time/drawing/pixel/concurrency limits remain. Frozen proposal instead requires horizontal compatibility and non-overlap in y, ranks nearest typed Figure/Table/Scheme/Chart, excludes nearest non-Figure or exact typed tie, then rejects equally close disjoint candidates sharing a key after overlap dedup; generic raster fallback persists. Neither applies a continuation-aware column search.

Three alternatives, with measured predictions (not executions of proposed code):

1. **Keep merged blocks and widen/relax pairing:** two column block overlaps both regions, 8.325pt gap each; it cannot recover two labels because normalization already destroyed identity. Choosing order or relaxing the tie gives arbitrary Figure 1, fails Figure 2 and honest ambiguity; reject.
2. **Emit each line and reuse existing merge unchanged:** columns become distinct candidate starts and 100% respective horizontal support; however sorted Figure 2 interrupts Figure 1 continuation at same baseline, as measured above; simply joining every nearby line also risks swallowing typed Table or body text. Reject as sufficient.
3. **Line identity plus bounded per-caption continuation and typed pairing:** separate structured line rectangles before classification; seek later lines within the same spatial column rather than stop on intervening unrelated columns; halt at another typed caption, enforce modest local line spacing and horizontal alignment, and use the assembled caption's geometry for region pairing while preserving ambiguity after overlapping-region dedupe. For example an experimental 0.5 × line-height maximum gap is 6.183pt for 12.366pt high lines: it includes the 1.634pt continuation and excludes the 15.634pt body reference in this fixture. It separates column starts (x120.046 to x340 gap 219.954), preserves the 5.100pt equal-support ambiguity and enables the tested Table/above geometry in principle. This is a **candidate**, not a validated universal cutoff: a nearby body line at 1.634pt or a true continuation at 15.634pt is geometrically indistinguishable under that rule. Span-level segmentation is still needed if two typed captions occur inside one structured line; no such case has been replayed. No numeric cutoff expansion, figure number or paper-specific rule, or arbitrary page-order tie is authorized.
