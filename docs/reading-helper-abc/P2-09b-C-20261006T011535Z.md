## Observations (noticed, not changed)

1. **After `fail()` the quota is `null`, as the brief says; that drops a true fact in one case.** A reader whose allowance is spent (`quota` first, then `mode` tier1) and whose shorter report then fails (a `noLlm` report after `mode`) sees only the failure sentence, not that the deep read was refused. I followed the ruling's text ("after `fail()`") because "this is the shorter report" would describe a report that is not shown; if the manager prefers the quota kept on a failure, it is one argument to `fail()`.
2. **The two company-budget and post-`mode` lines say "This is the shorter report." while no model report is on the page at all.** With `report: null` the page shows the reading's own Tier 0 content, so "the shorter report" has no visible referent. The words are the ruled copy (§1g.14) and I did not change them; for A or the manager to weigh at §3d 18, together with the Decision block's "did not finish" sentence from P2-09 observation 1.
3. **A refusal with no report is not cached, so a revisit asks again.** `readCached` rejects `noLlm`, and a `report: null` settle writes nothing, so the second open of the same paper issues a new request (and a new quota decision), and the line returns with its answer. That is today's behaviour for every no-model-layer open, unchanged here.
4. **The line appears when the stream settles, not when the `quota` event arrives.** The state's `quota` is set with the settle, like the report, so during the stage bar the reader sees no notice yet. Nothing in the brief asked for earlier, and showing it earlier would be a second state in the hook.
5. **When the stream throws after a quota and the JSON fallback answers, the fallback's own quota (or none) stands, not the stream's.** That is the "last quota the server sent". The fallback is the second POST that P2-07's O-B1 concerned; a stream that fails after a first quota is not covered by a test and is unchanged.
6. **The `ModelReportState` field is required, not optional.** No other file constructs a `ModelReportState` (I grepped `src`), so nothing needed updating; a future test double would have to include it.
