## 1. Cluster C — hyphens at line ends

### 1.1 Mechanism
`joinProse` (`pdf-outline.ts:759-801`), line 795: `else if (/[‐-―-]$/.test(current)) current = current.slice(0, -1) + line.text`. The class is U+2010-U+2015 plus `-`; any line that ends in one of them loses it and the next line is glued on **with no space**. It decides nothing from the words. Three consequences, all measured on the 52 line-end hyphens that reach the body or a caption of the paper:

* the old rule is right 41 times (the joined word is one the paper itself writes whole, or the right half is a fragment) and wrong 11 times (79 % right);
* U+2014 / U+2013 at a line end are dashes, not broken words, and are eaten too (the design spec in the set: `typing —` + `everything` reads `typing everything`); U+2212 (the minus the paper uses for ranges) is not in the class, so a range split across lines reads `(15− 25)` (that one is P9-01's join-spacing);
* with an ASCII hyphen between digits it glues the numbers (`10-` + `20` reads `1020`); none in the owner's body, a latent bug.

Why the caption path differs: `buildOutline` (`:902-922`) collects the caption's own lines and joins them with `[caption.caption, ...rest].join(" ")` at **`:919`**: no call to any mender, so the hyphen stays and a space is added: `Super- saturations`. A third site, the wrapped heading (`:926`, `heading = `${heading} ${next}``), has the same gap; no heading of the owner's paper wraps on a hyphen.

### 1.3 The risk the brief names: crystallo-mechanical
The paper writes **`crystallo-mechanical`** and, next to it, **`crystallo-electrochemical`** (hyphenated). The break is `crys-` + `tallo-mechanical`: the right token carries its own inner hyphen. The rule drops only the line-end hyphen, so the output is `crystallo-mechanical`, as printed (checked in the prototype). The risk that remains is the symmetric one: a closed compound whose two halves are both words of the document and whose joined form never occurs whole gets a hyphen it should not have. This list is the one place the rule uses an English prior instead of the document; it is a judgment call for the manager, measured at 2 decisions (`nanowire`, `nonequilibrium`), 0 wrong.

### 1.4 Design (the rule in words)
Build once per document the set of words seen whole (a token is dropped from the set when it is a line's last token before a hyphen or the next line's first token). At a line-end **hyphen** (U+002D, U+2010, U+2011, U+00AD only; a dash is punctuation and stays with a space after it), in this order:
1. digit before and digit after: a range, keep the hyphen (`10-20`);
2. the next line starts with a non-letter (a bracket, a symbol, a digit): keep the hyphen (`non-⟨003⟩||ND`);
3. no letters before the hyphen (`(de)-`): join as today;
4. the right token holds a digit, two or more lower-to-upper steps (a formula), or opens with a capital (a Title-Case or acronym compound): keep the hyphen;
5. the joined form occurs whole (as a word, or as a hyphenated compound): join; the hyphenated form occurs whole: keep;
6. the right half is not a word of the document, or the left half is not: join (a fragment of a word);
7. closed prefix with no hyphenated use in the document: join;
8. else both halves are words of the paper and the joined form never occurs: keep the hyphen, no space.
With no evidence in the document (a one-page upload) steps 5-8 fall to "join", which is today's behaviour: a short document cannot get worse. The caption fold and the heading wrap call the same function.

### 1.5 Code sketch (the prototype, with logging, is `proto/pdf-outline.proto.ts:mend`)
```ts
const HYPHEN_END = /[-\u2010\u2011\u00AD]$/;   // U+002D, U+2010, U+2011, soft hyphen; not U+2010-2015: an en or em dash is not a broken word
function mend(cur: string, next: string, v: Vocab): string {
  const left = cur.slice(0, -1), joined = left + next, kept = `${left}-${next}`;
  const rtok = /^\S+/.exec(next)?.[0] ?? "", whole = rtok.replace(/[^\p{L}\p{N}-]+$/u, "").toLowerCase();
  const l = /\p{L}+$/u.exec(left)?.[0].toLowerCase(), r = /^\p{L}+/u.exec(whole)?.[0];
  if (/\p{N}$/u.test(left) && /^\p{N}/u.test(next)) return kept;                      // 10-20
  if (!r) return kept;                                                                  // non-⟨003⟩||ND
  if (!l) return joined;                                                                // (de)-intercalated
  if (/\p{N}|(?:\p{Ll}\p{Lu}.*){2}|^\p{Lu}/u.test(rtok)) return kept;                  // Li-NixCoyMnzO2, Lithium-Ion
  if (v.words.has(l + whole) || v.compounds.has(l + whole)) return joined;              // the paper writes it whole
  if (v.compounds.has(`${l}-${whole}`)) return kept;                                   // ...or hyphenated
  if (!v.words.has(r) || !v.words.has(l)) return joined;                                // a fragment of a word
  return CLOSED_PREFIX.has(l) && !v.prefixes.has(l) ? joined : kept;                    // both words, joined never occurs
}
// joinProse :795 -> else if (HYPHEN_END.test(current)) current = mend(current, line.text, vocab);
// caption :919   -> fold [caption.caption, ...rest] with the same mend(), not join(" ")
// buildOutline: const vocab = vocabularyOf(lines)   // words, compounds, prefixes: lower-case, from every line, fragments excluded
```

## 3. Cluster E — a caption inside a sentence

### 3.2 Design
A large same-page gap is a float (a figure, a table, a box), not a paragraph, **while the sentence above it is unfinished**: the line before ends with no `. ! ? : ;` (a closing quote or bracket after it counts), the line after opens with a lower-case letter, a digit or a bracket, **and the gap is more than 3 pitches** (a real paragraph gap is 1.5-2 pitches). The third condition is the one that matters on other PDFs: without it the synthetic `paper-l.pdf` (paragraph gaps of 2 pitches, lines cut without a full stop) merged 15 paragraphs; with it, 0. A capital after the gap stays a break (conservative: `Raman maps then show...` after a figure is lost, a false cut, never a false merge).

### 4.2 Design: the equation island
A **stack** is a run of two or more consecutive same-page lines that are each a *short fragment* (at most 40 characters, no run of 4 or more letters, at least one letter or digit) and each at most 0.8 of the paper's leading below the one before. The leading is the median of the same-page gaps that are at least 0.6 of the body size (the tight rows do not pull it down; the section's own 25th-percentile pitch, which `joinProse` uses, would be dragged down by a section full of equations). Then:
* **display** (the line before ends a sentence, or the line after opens a capital): the rows, joined by a newline, become **one unnumbered equation** through the existing path (`equations.push({text})` + `blockMarker`), so `sectionParagraphs` lifts it, the map no longer lists scraps, and `components/reader/math.tsx:96` renders it in `<code class="block whitespace-pre-wrap font-mono">`, which keeps the rows as rows. It is not the formula; it is one readable block of what the page set, instead of ten paragraphs. (The Markdown export carries no body, so nothing to port.)
* **inline** (the line before ends with no full stop and the line after opens lower-case): the rows are joined with spaces into the sentence.
* **sandwich** (§2.1): a fragment row, a text row that *opens with an operator* (`× = + ÷ − · ∑ Σ /`), a fragment row, each within 0.8 leading: merged as `numerator / denominator row-text` into the sentence. The operator-start requirement keeps this off the `f` subscripts of §2.2/§2.5 (`0−4 μm ... 8−15 μm` around a prose row), which are P9-01's script folding and which an earlier, looser version of mine wrongly took.
This reverses nothing in §1h.41 (c): the owner's cheap rule is about a *single line* of symbols, and stays (single lines stay in their paragraphs). A stack needs two or more tight rows. It is worth saying to the owner, as the one place the cheap rule gets an exception.

### 4.3 Code sketch (the prototype is `foldStacks` in `proto/pdf-outline.proto.ts`)
```ts
// buildOutline: const leading = median of same-page gaps >= 0.6 * body.size
// flush():      joinProse(foldStacks(held, leading, (t) => { equations.push({ text: t }); return blockMarker(equations.length - 1); }))
const ROW = (l: PdfLine) => !l.block && l.text.length <= 40 && !/\p{L}{4,}/u.test(l.text) && /[\p{L}\p{N}]/u.test(l.text);
function foldStacks(lines: PdfLine[], leading: number, lift: (text: string) => string): PdfLine[] {
  const near = (a: PdfLine, b: PdfLine) => a.page === b.page && a.y > b.y && a.y - b.y <= 0.8 * leading;
  const out: PdfLine[] = [];
  for (let i = 0; i < lines.length; ) {
    let j = i;
    while (ROW(lines[i]) && j + 1 < lines.length && ROW(lines[j + 1]) && near(lines[j], lines[j + 1])) j++;
    const rows = lines.slice(i, j + 1), prev = out[out.length - 1], next = lines[j + 1];
    if (j > i) {                                              // two or more tight short rows
      const inline = prev && !/[.!?:;]$/.test(prev.text.trim()) && next && /^[\p{Ll}\p{N}(]/u.test(next.text);
      out.push(inline ? { ...rows[0], text: rows.map((r) => r.text).join(" "), x: prev.x, y: prev.y - leading }
                      : { ...rows[0], text: lift(rows.map((r) => r.text).join("\n")), block: true });
      i = j + 1; continue;
    }
    out.push(lines[i++]);   // + the sandwich: ROW, a text row opening with an operator, ROW, all near => "a / c b" on one line
  }
  return out;
}
```
