## Behaviour differences from the old Python helper (for A / manager)

1. A line that is only a 1–4 digit number is always a folio to pdf.js (`FOLIO` in `pdf-outline.ts`): a lone "2024" mid-page is dropped; the helper kept a bare number whose value did not track the page sequence. The 4-05 tests now assert pdf.js's behaviour and say so. Not changed in `pdf-outline.ts` (it would alter how every PDF link reads).
2. A bare number repeated at the same height on most pages is furniture to pdf.js (dropped); the helper kept a non-tracking one.
3. `buildOutline` calls a PDF with < 200 characters of text "no-text-layer"; two 4-05 fixtures were one or two short lines below that and got one extra prose line each.
4. Stamp-shaped title lines are now ignored by `titleOf` for links and uploads alike (added so the 2-06 stamp test holds on the new path).
