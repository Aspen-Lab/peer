## The rules as built

1. **The build's commit on the version line.**
   - `src/lib/build-ref.ts` (new):
     - `buildRef({ vercelSha, git })` is pure. It takes Vercel's commit when one is set; a malformed one gives `""`, and git is not asked. Otherwise it takes git's answer, and `""` if git throws. Anything that is not 7–40 hex characters (`/^[0-9a-f]{7,40}$/i`) gives `""`. The result is cut to seven characters, in lower case.
     - `readBuildRef(dir)` wires it to the two real sources: `process.env.VERCEL_GIT_COMMIT_SHA`, and `execFileSync("git", ["rev-parse", "--short=7", "HEAD"], { cwd: dir, timeout: 3000, encoding: "utf8", stdio: ["ignore", "pipe", "ignore"] })`. git's stderr is not printed, and nothing else is read.
   - `next.config.ts` gets the import and `env: { PEER_BUILD_REF: readBuildRef(__dirname) }`, last, with a comment. No other key changed. The value is fixed when the file is evaluated, at `next build` or `next dev` start.
   - `version-line.tsx` reads `process.env.PEER_BUILD_REF`, which Next inlines, inside the render. It shows the value only if it is seven lower-case hex characters, as `· <span title="Built from commit c550daa">c550daa</span>` between the version and the dot before "What's new". With no value the markup is today's, byte for byte (pinned).
