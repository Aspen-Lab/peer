## 2. The rules, as built

All in `pdf-outline.ts`. In `lineOf`, when a raised mark is not a citation, the whole-mark judgement is kept exactly as P9-08 built it (`superscripts` = the whole mark is in `SUPERSCRIPT` and there is text before it). New: when the mark has a character outside `SUPERSCRIPT` (a letter, a point, a slash) **and there is text before it**, `exponentsOf(runs, i, end)` returns the runs inside it that are an exponent or charge, and `lineOf` writes those (and only those) through the `SUPERSCRIPT` map (`exponents`, a set of run indexes, beside `superscripts`).

`exponentsOf` walks the runs of the mark that have text (a stored space run is skipped, so it never stands between the two judged runs). A run is the exponent or charge of **the raised run before it** when all of these hold:

1. **It sits higher**: its baseline is above that run's by more than `SUPERSCRIPT_RISE` (1pt). A run at the first's own height, or within 1pt above it, is not.
2. **It is no larger**: `run.height <= before.height`. A larger run is not.
3. **It is made only of characters in `SUPERSCRIPT`** (digits, `+`, `−`, `-`, `–`). A letter or a point in it (`c3`, `2.5`) leaves the mark as the PDF has it.
4. **It touches that run**: it starts less than `LABEL_TOUCH_EM` (0.2) × the earlier run's height past the earlier run's right edge. A negative gap (the stored width of a raised word can run past where the charge starts) touches; a run set 3pt apart does not and is read as a word of its own.
5. **A sign and its digits stored as two runs on that higher level are one charge** (my extension of the brief's rule, in the spirit of its "that run's own exponent or charge", and the analogue of P9-08's "a sign and its digits stored as two raised runs print as one mark"): a run that follows an exponent just taken, within 1pt of its baseline, no larger, digits and signs only, touching it, is taken too (`−` `1` is `⁻¹`). It only ever follows an exponent that rule 1 took; it cannot start a conversion.
6. **A mark with nothing before it keeps P9-08's reading** (the line-head rule, "a footnote number, a charge"): no text before the mark, no exponent is taken.

The run below it is written as today (letters stay as the PDF has them). Unchanged, by construction and by the tests: a one-level raised mark (`Ni` + `2+` is `Ni²⁺`), a citation after a word (dropped), a mark with a point or slash (`1/2`), the label rule (`f` + `0−4 μm` is `f(0−4 μm)`), a mark made only of digits and signs (whole-mark rule), the head-of-line mark. The text the matcher folds is unchanged in alphabet (`²⁺` already folds).
