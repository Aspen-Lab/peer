1. **A long unbroken run in the paper's text overflows the column once the text steps scale the paper (E1).** Mechanism: the paper's paragraphs wrap at spaces and hyphens only (`overflow-wrap: normal`, `hyphens: auto` with no dictionary in the walk's Chromium); a slash-joined 43-character chemical name has no break opportunity, so it is 338 px at the default size and 446 / 490 / 541 px at 1.32 / 1.45 / 1.6, against a 416-px column at 1024 and 1093 (538 at 1242).
