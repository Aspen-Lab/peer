## Acceptance (§3d item 1) as far as tests reach

- Server: same upload opened twice → extractor once (memory), and once across a simulated restart (sidecar). Concurrent reading + report requests share one extraction.
- Browser: second mount of a private PDF reads the report and the reading from localStorage, so no second report request is made (the request lives in the effect, which the cache short-circuits: `if (... cached ...) return;`). Quota "+1" follows from that; not measured against the live quota store.
- Owner isolation: the cache is consulted only after `ownedUpload` returns a meta; a refusal returns "unavailable" with no doc; another owner key is another cache key.
