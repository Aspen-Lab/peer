### `web/src/components/reader/question-field.tsx` (new)
Pure functions, each tested:
- `showChips({ focused, lines, gist })`
- `nextGist(gist, lines)`: typing any question turns the gist off.
- `addLineAfter(lines, index)`: Enter. Adds a line after a written one up to 5; reuses an existing empty line instead.
- `removeLine(lines, index)`: removing the last line leaves one empty line.
- `fillNextLine(lines, text)`: a chip fills the next empty line, or appends while there are fewer than 5; returns `focus: -1` when full.
- `chipGroups({ paperId, byPaper, previousPaperId, challenges })`, in order:
  1. "From your last paper": the previous paper's items, only when that paper is a different one.
  2. "Common questions": the four chips verbatim. The "differ" chip is `kind: "prefix"` and fills `"How does this differ from "`. "Just get the gist" is `kind: "gist"`.
  3. "From your challenges": only when the page passes phrases.
  - Empty groups are omitted.
- `focusFirstEmptyQuestion()`: the page's `q` handler. It focuses the first `input[data-ask-line]` whose value is empty, or else the last one.

The `QuestionField` component:
- Reads the store once, at mount: its own lines and gist, the `lastPaperId` from before this visit, and `byPaper`. It keeps lines, gist and focus in local state and writes them through with `set()`.
- It does not subscribe to the store, so a server render reflects the state.
- With no question: the eyebrow label "Before you read" and one input with the placeholder. No button, hint or chips.
- Each line has a remove control `×` (aria-label "Remove question N") once there is more than one line or the line has text.
- A counter `N/200` appears only past 160 characters; the input has `maxLength=200`.
- The chips, hint and groups show while the field has focus (focus-within), holds a question, or has the gist chosen.
- The gist chip has `aria-pressed`. Chips are disabled when all 5 lines are written; the gist chip stays enabled.
- The caret is placed at the end after a chip or a new line, via a ref and an effect with no setState.
