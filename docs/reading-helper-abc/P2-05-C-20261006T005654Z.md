## Observations (noticed, not changed)

1. **The upload-fallback `<PaperNotes>` mount is unchanged.** The ruling says both mounts pass `settledQuestions(asked)` and `model.report?.forYourQuestions`. The first mount sits in `UploadFallbackReading` (an upload whose text is unavailable), which has neither `asked` nor `model` in scope, renders no question field, and requests no report. Passing the props there would need a new store subscription in that component. I left it as `<PaperNotes paper={paper} />` (pinned by a test) so that note is byte-identical to today. If the manager wants questions typed on an earlier visit carried there, it is three lines.
2. **The note is made once.** `open()` creates the paper's reading note the first time "Take notes" is pressed and reopens it afterwards, so questions settled, or a report arriving, after that never reach the note. That is the existing template-at-creation behaviour, not something this item changes. A note taken from the saved page (`saved/page.tsx`, untouched as ruled) has no questions section either, since no report or questions are in scope there.
3. **A new report while the old one shows.** After a question is settled, `settledQuestions(asked)` is current immediately while `model.report` may still be the previous report until the new one arrives. The frontmatter then lists the new set while the block shows the old answers (the page shows the old block in the same window). The note is robust to it, because it matches on question text and leaves out stale entries; the export block renders what the report carries, as the page does.
4. **`readNextLabel` uses the raw map heading.** The page's Read next label is `§${section.heading}` with no `displayHeading`, while every attribution is set with it. I mirrored the page (raw heading) so the words match; an all-caps heading would read `§RESULTS` in Read next and `§Results` in a quote. If P2-04's label is ever changed to `displayHeading`, `questionEntryLines` follows in one place.
5. **The background mark in Markdown is ` · background`** after the minutes: the page sets the word after the label with a gap, and the export has no gap to use. The brief left the form open.
6. **Question text is not escaped for emphasis.** The question is a bold line (`**…**`); a question that itself contains `*` would render with odd emphasis. Quotes, backslashes and line breaks are handled in the frontmatter; the body line only collapses whitespace.
7. **`readingNote`'s second argument is a union** (`string | ReadingNoteExtras`), so the two existing tests that pass a time string (`notes.test.ts`, `saved/page.test.tsx`) keep working untouched, as the manager's ruling required.
