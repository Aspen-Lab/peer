## Findings, ranked (privacy first)

### SHOULD-FIX

**F1 — the kind-only rule does not reach a Gemini reader's server log (item 5).** `lib/llm/providers/gemini.ts:509` (`generateJsonText`, the call every report, explain, plain, guide and figure-binding prompt goes through for a Gemini key) catches the SDK's error and logs it whole: ``console.warn(`[gemini-api] ${id} failed:`, err)``; so do `:486` (digest), `:528` (vision) and the Vertex path `:333`, `:359`, `:386`. The error is thrown away after that (the caller gets a generic "All Gemini API models returned empty response"), so `deep-report.ts`'s kind-only catch never sees it, and its comment "so the message never reaches a log" is not true for this provider. Reproduction above (item 5): the SDK builds the error message from the response body; with a body that echoes the prompt, the prompt's first 600 characters — the task text and the paper's title, an upload's title being private — were in two log lines (once per model in the chain). This is exactly A P5-03f's F1 hypothetical (a provider whose error body quotes its input); whether Google's error bodies ever do is not measured (BLOCKED: no real Gemini call), the same standing F1 had on OpenAI. Same class, outside the papers routes, not reproduced: `lib/feed/tier2-rerank.ts:143` logs a rerank error whole. Smallest fix: the kind (`err instanceof Error ? err.name : typeof err`) at the six Gemini lines, with one red-first test per provider path; it needs a ruling because §1h.16/§1h.17 named the deep-report and figure-binding lines only.

### NOTES

- **N1 — what the shape rule does not catch (all ruled or recorded, listed for the manager).** Probed through `questionTerms`: a hyphen-grouped phone number of 10 or 11 digits is **1 term** (12 and 14 characters) — §1h.16 (d) and §1h.17 (b) name phone numbers, but a phone number has at most 15 digits (E.164), so a 16-digit threshold cannot catch one; a dotted-quad IPv4 address is **4 terms** of 3 digits (the dot clause needs letters on both sides); a 15-character key-like body (`sk-` + 12) is 1 term; a run of 20 or 24 letters alone is 1 term (C's P5-04 question 3); four spaced 4-digit groups are 4 terms (ruled, §1h.17 (b)); and, by the same count, years joined by hyphens (16 digits), a DOI (`/`), an ORCID iD, a UUID and a 32-character hex string give no term (§1h.18 (c)). A card number typed with spaces, the commonest way, is the form the rule leaves alone.
- **N2 — /privacy says what the request does and that the copy is stored, not that the stored copy ranks on its own.** For a signed-in reader the account's ledger, question terms included (`withQuestions` defaults to true), is read by the nightly digest (`app/api/jobs/dispatch-digests/route.ts:522`) and the dashboard pool preparation (`lib/dashboard/prepare-pool.ts:136`) with no request from the reader.
