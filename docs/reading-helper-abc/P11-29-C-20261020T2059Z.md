## The rules

1. **The separator takes focus without moving the page.** `.reader-divider` (the existing rule, `cursor` / `touch-action`) gains `scroll-margin-top: calc(4rem / var(--page-zoom, 1));` — the pane's own sticky `top`. Only the top margin: `scroll-margin-block` (Tab from the paper's last link to the margin's separator throws the window to 0) and `scroll-padding-top` on `html` (moves every `scroll-mt-20` landing) are refused, in a comment on the rule and by a test.
2. **Smooth scrolling respects reduced motion.** `html[data-scroll-behavior="smooth"] { scroll-behavior: smooth; }` now stands inside `@media (prefers-reduced-motion: no-preference) { … }` (the query the panes' transitions already use). `layout.tsx` still sets `data-scroll-behavior="smooth"`; default motion is unchanged.

## Unsettled, and for the manager

1. **3 px under Fit at 1920 × 1080 (zoom 1.2143)** — B's measured residual, accepted by the brief. Cause: the masthead (48 px) is not scaled by the zoom and the article's 16 px is, so `4rem / zoom` is 3 px short. I measured, as an injected style only (nothing committed, the control step of one run: `scratchpad/p11c29/out/sep-alt-1920x1080-fit1-motion.json`), `calc(3rem / var(--page-zoom, 1) + 1rem)`: **0** at 1920 Fit on for all four cases. Taking it would also mean changing my test's "equals the pane's own top" case, which is why I did not.
2. **Explicit JS smooth scrolls ignore both the CSS and the setting:** `components/reader/evidence-quote.tsx:244`, `app/papers/[id]/page.tsx:973`, `components/notes/note-tags.tsx:261` pass `behavior: "smooth"`; `components/keyboard.tsx:84` already honours `reduce`. They are components, not mine; a follow-up if the manager wants the whole page quiet under `reduce`.
3. **The blank band** (A11's `tab-end` pictures) is B P11-24's capture artefact and is untouched here; rule 2 removes the animation only for a reader who asked for less motion, so a default-motion harness still needs the settle wait.
4. **Test strictness:** rule 2's case accepts only the file's own form `@media (prefers-reduced-motion: no-preference)`; an equivalent `@media not (prefers-reduced-motion: reduce)` would be red. Deliberate (one convention), easy to loosen.
5. **A flake in my own harness, fixed:** the first base matrix read 0 for the very first case of two runs (taken before the page had finished loading); I added a warm-up case and a second repetition of the `top` and `mid` cases and re-ran the whole base matrix (all 16 runs then agree). The numbers above are from the re-run.
