## What changed

### `web/src/lib/reader/question-examples.ts` (new)

`exampleQuestions({ profile, byPaper, paperId }): ExampleGroup[]` builds two groups.

**Group 1, `ASK.fromEarlier`.** Questions from every `byPaper` entry except this paper's.
- Entries are taken newest `updatedAt` first; each entry's items keep their order.
- At most 6.

**Group 2, `ASK.fromProfile`.** The profile turned into questions with the `ASK.examples` templates, in this order:

| Source | Template |
|---|---|
| `phrasesFromText(currentChallenges, 4)` | "Does this help with <phrase>?" |
| `phrasesFromText(currentProject, 2)` | "How does this relate to <phrase>?" |
| `researchTopics` (first 2) | "What does it say about <topic>?" |
| `preferredMethods` (first 2) | "Could I use <method> here?" |

- At most 8 in all. An empty field is skipped.

**Rules for both groups.**
- Every example is de-duplicated against everything already offered, in either group. The comparison ignores case and collapses whitespace.
- Each example is cut to 200 characters, the question line's `maxLength`.
- An empty group is left out; with nothing to draw on the result is `[]`.
- The function is pure.

## Observations for the manager (as ruled; not changed)

1. **Single-word examples.** When `phrasesFromText` runs short of phrases it falls back to single keywords. With a usual challenges text that gives examples like "Does this help with dendrite?" and "Does this help with growth?", and "How does this relate to solid-state?" from the project. They come from the ruled `phrasesFromText(…, 4)` and `(…, 2)` calls. Should only multi-word phrases be used?
2. **Template words become route terms.** The templates' own words "help", "relate", "say" and "here" are not in `ROUTE_STOPLIST`. So "Does this help with growth?" routes on two terms, `help` and `growth`, and is not vague. The stoplist lives in `lib/papers/reading-map.ts`, outside this item. Should those words be added there?
3. **The cap squeezes out methods.** With a rich profile the 8-example cap is reached before the topics and methods, so methods never show. That follows the ruled order.
4. **Long chips wrap.** Long examples wrap inside the pill-shaped chip, with the text centred. This is cosmetic.
