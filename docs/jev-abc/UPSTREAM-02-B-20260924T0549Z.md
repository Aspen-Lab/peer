What would need to change, keeping Jev's invariants (capability unforgeable from request data, no body/query authority, explicit server-funded requests fail closed without entitlement, Tier 0 anonymous path, BYOK distinct, private caches):

1. Port `entitled-context.ts` + `spend-scans.test.ts` (its enforcement scan) as a pair — the scan is meaningless without the type it scans for, and vice versa the type buys nothing without a scan stopping a future optional-ctx regression (FINDING in upstream's own header: "a helper declaring `ctx?: EntitledContext` compiles and re-opens the hole exactly as it stood before").
2. Port `metered.ts` + `usage/context.ts` + `usage/events.ts` (dependency order: context → events → metered, since metered imports both).
3. 4. 5. **What "reservation" and "settlement" would then mean, concretely (per the manager's brief and FINDING B-03):** "reservation" = an atomic `usage_counters` increment against a Jev-specific (or, if extended to the newly-reachable Gemini paths, a Gemini-Tier2-specific) key, checked and refused **before** the call, exactly as `consumeDeepReport`/`consumeForcedRebuild` already do for their two features. "Settlement" = recording the real `usage.input_tokens`/`output_tokens` afterward via `recordUsageEvent`/`recordUsageEventAwaited`, optionally trued up against the reservation with a second signed `increment` call (P3-B DESIGN §0.3 already worked this out in detail for Jev specifically and rates it optional, not required, for §1j's fail-closed bar). **What is still missing even after full Option 1 adoption:** nothing upstream currently reserves *anything* for the general Tier-2/digest/report/query-gen/figure surface — only a per-scope hourly rate limit that fails open (FINDING B-03). Adopting Option 1 as-is would make that surface operator-funded for every signed-in reader with **no atomic cap at all**, which is a regression relative to §1j's bar, not merely "not yet extended to Jev." A genuinely §1j-compliant Option 1 therefore requires **an additional new breaker for the general LLM surface**, mirroring `deep-report-quota.ts`'s shape, that upstream itself does not yet have — this is new work either way, on top of the port.
6.
