is the first time the sheet builder ever saw a real OpenAlex-shaped DOI. Impact: every DOI link
shown to a labeler for an OpenAlex-only work in this run's blinded sheet is a broken link (double
`https://doi.org/` prefix does not resolve). Not a §1u compliance issue (no secret, no budget, no
channel leak) — a data-quality bug in new code. Worked around for the human-facing label sheet
below by rebuilding each link from the bare DOI in the separate, already-generated
`blinded-sheet-key.json` instead of trusting `blinded-sheet.json`'s own `doiUrl` field. Not fixed in
