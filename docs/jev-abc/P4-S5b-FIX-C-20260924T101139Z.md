An evicted owner's history is genuinely lost, not merged, hidden, or guessed at — the accepted cost of any finite bound, matching this campaign's own established pattern for other bounds (e.g. `RECENTLY_SHOWN_CAP`, `DELIVERED_LOCAL_CAP` itself).
